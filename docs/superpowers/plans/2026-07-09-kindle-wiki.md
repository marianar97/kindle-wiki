# kindle-wiki Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sync Kindle highlights from a device's `My Clippings.txt` into per-book Obsidian markdown files, plus a `CLAUDE.md` schema so a Claude agent maintains a concept wiki over them.

**Architecture:** One stdlib-only Python script (`sync.py`) parses the clippings file in memory and regenerates `vault/books/*.md` (immutable, Obsidian-native format with block-ID anchors). A `CLAUDE.md` schema defines the agent-run ingest and lint operations over `vault/concepts/`. Everything is manual: run `sync.py` after plugging in the Kindle; say "ingest" in a Claude Code session.

**Tech Stack:** Python 3.9 (macOS CLT system python), stdlib only. pytest 8 for tests. No other dependencies.

**Spec:** `docs/superpowers/specs/2026-07-09-kindle-highlights-obsidian-wiki-design.md` (rev 3 + option B format + bookmarks + manual-only).

## Global Constraints

- Python 3.9 compatible: every module starts with `from __future__ import annotations` (system python is 3.9.6; bare `str | None` annotations fail at runtime otherwise).
- `sync.py` uses the standard library only. pytest is for tests only.
- `sync.py` stays under 300 lines; functions under 30 lines.
- No emojis anywhere — code, output, generated markdown, commits.
- English-language clippings format only (`- Your Highlight on page ...`).
- Book files are fully generated: `sync.py` overwrites them wholesale, writes temp-then-rename, and never reads them back except to diff and count new clip IDs.
- Stable clip ID = first 12 hex chars of SHA-1 over `title|type|location|text`, rendered as an Obsidian block ID (`^abc123def456`).
- Run tests from the repo root: `python3 -m pytest tests/ -v`.
- Commit after every task.

```python
#!/usr/bin/env python3
"""Sync Kindle highlights from My Clippings.txt into vault/books/*.md."""
from __future__ import annotations

import hashlib
import re
from dataclasses import dataclass
from datetime import datetime

SEPARATOR = "=========="
DATE_FMT = "%A, %B %d, %Y %I:%M:%S %p"
TITLE_RE = re.compile(r"^(?P<title>.*?)(?:\s*\((?P<author>[^()]*)\))?\s*$")
META_RE = re.compile(
    r"^- Your (?P<type>Highlight|Note|Bookmark)"
    r"(?: on page (?P<page>[^|]+?))?"
    r"(?:\s*\|?\s*(?:at )?location (?P<location>[\d-]+))?"
    r"(?:\s*\|\s*Added on (?P<date>.+))?$"
)


@dataclass
class Clip:
    title: str
    author: str | None
    type: str  # "highlight" | "note" | "bookmark"
    page: str | None
    location: str | None
    date: datetime | None
    text: str


def parse_entry(block: str) -> Clip | None:
    lines = [line.rstrip("\r") for line in block.split("\n")]
    while lines and not lines[0].strip():
        lines.pop(0)
    while lines and not lines[-1].strip():
        lines.pop()
    if len(lines) < 2:
        return None
    m_title = TITLE_RE.match(lines[0].lstrip("\ufeff"))
    m_meta = META_RE.match(lines[1])
    if not m_title or not m_meta:
        return None
    date = None
    if m_meta.group("date"):
        try:
            date = datetime.strptime(m_meta.group("date").strip(), DATE_FMT)
        except ValueError:
            pass
    page = m_meta.group("page")
    author = (m_title.group("author") or "").strip()
    return Clip(
        title=m_title.group("title").strip(),
        author=author or None,
        type=m_meta.group("type").lower(),
        page=page.strip() if page else None,
        location=m_meta.group("location"),
        date=date,
        text="\n".join(lines[2:]).strip(),
    )


def parse_clippings(text: str) -> list[Clip]:
    clips = []
    for block in text.lstrip("\ufeff").split(SEPARATOR):
        clip = parse_entry(block)
        if clip is not None:
            clips.append(clip)
    return clips
```

```python
    def id(self) -> str:

def dedupe(clips: list[Clip]) -> list[Clip]:
    best: dict[str, Clip] = {}
    order: list[str] = []
    for clip in clips:
        cid = clip.id
        if cid not in best:
            best[cid] = clip
            order.append(cid)
        elif (clip.date or datetime.min) > (best[cid].date or datetime.min):
            best[cid] = clip
    return [best[cid] for cid in order]
```

```python
TYPE_RANK = {"highlight": 0, "note": 1, "bookmark": 2}


def location_start(clip: Clip) -> int:
    if not clip.location:
        return 0
    return int(clip.location.split("-")[0])


def group_books(clips: list[Clip]) -> dict[tuple[str, str | None], list[Clip]]:
    books: dict[tuple[str, str | None], list[Clip]] = {}
    for clip in clips:
        books.setdefault((clip.title, clip.author), []).append(clip)
    for key in books:
        books[key].sort(key=lambda c: (location_start(c), TYPE_RANK[c.type]))
    return books
```

Note: the spec's "attached note" rule (a note whose location falls inside a
highlight's range renders under that highlight) is satisfied by this sort —
notes and highlights render identically in option B, so position is the only
attachment semantics left.

```python
def meta_parts(clip: Clip) -> list[str]:
    parts = []
    if clip.page:
        parts.append(f"p. {clip.page}")
    if clip.location:
        parts.append(f"loc. {clip.location}")
    if clip.date:
        parts.append(clip.date.strftime("%Y-%m-%d"))
    return parts


def meta_line(clip: Clip) -> str:
    return " · ".join([clip.type] + meta_parts(clip))


def render_clip(clip: Clip) -> str:
    if clip.type == "highlight":
        quoted = "\n".join(f"> {line}" for line in clip.text.split("\n"))
        return f"{quoted}\n>\n> — {meta_line(clip)} ^{clip.id}"
    if clip.type == "note":
        return f"Note: {clip.text}\n— {meta_line(clip)} ^{clip.id}"
    return f"{' · '.join(['Bookmark'] + meta_parts(clip))} ^{clip.id}"
```

```python
import json

GENERATED_NOTE = (
    "<!-- GENERATED by sync.py — edits are overwritten on every Kindle sync -->"
)


def slugify(title: str) -> str:
    slug = re.sub(r"[^a-z0-9]+", "-", title.lower()).strip("-")
    return slug or "untitled"


def render_book(
    title: str, author: str | None, clips: list[Clip], synced_on: str
) -> str:
    lines = [
        "---",
        f"title: {json.dumps(title, ensure_ascii=False)}",
        f"author: {json.dumps(author, ensure_ascii=False) if author else 'null'}",
        f"last_synced: {synced_on}",
        "---",
        GENERATED_NOTE,
        "",
        f"# {title}",
    ]
    if author:
        lines.append(f"*{author}*")
    lines += ["", "## Highlights", ""]
    body = "\n\n".join(render_clip(c) for c in clips)
    return "\n".join(lines) + f"\n{body}\n"
```

Note: `json.dumps` produces a valid YAML double-quoted scalar — it handles
titles containing quotes or colons without a YAML dependency.

```python
from pathlib import Path

LAST_SYNCED_RE = re.compile(r"^last_synced: .*$", re.MULTILINE)
BLOCK_ID_RE = re.compile(r"\^([0-9a-f]{12})")


def _strip_volatile(text: str) -> str:
    return LAST_SYNCED_RE.sub("last_synced:", text)


def write_vault(
    books: dict[tuple[str, str | None], list[Clip]],
    vault_dir: Path,
    synced_on: str,
) -> tuple[int, int]:
    vault_dir.mkdir(parents=True, exist_ok=True)
    new_clips, changed_books = 0, 0
    used: set[str] = set()
    for (title, author), clips in sorted(books.items(), key=lambda kv: kv[0][0]):
        slug = slugify(title)
        if slug in used:
            slug = f"{slug}-{slugify(author or clips[0].id)}"
        used.add(slug)
        path = vault_dir / f"{slug}.md"
        content = render_book(title, author, clips, synced_on)
        old = path.read_text(encoding="utf-8") if path.exists() else ""
        if _strip_volatile(old) == _strip_volatile(content):
            continue
        old_ids = set(BLOCK_ID_RE.findall(old))
        new_clips += sum(1 for c in clips if c.id not in old_ids)
        tmp = path.with_suffix(".md.tmp")
        tmp.write_text(content, encoding="utf-8")
        tmp.replace(path)
        changed_books += 1
    return new_clips, changed_books
```

Note: iteration is sorted by title so slug-collision resolution is
deterministic across runs (the alphabetically-first book keeps the bare slug).

```python
import argparse
import shutil
import sys

DEFAULT_SOURCE = Path("/Volumes/Kindle/documents/My Clippings.txt")


def run(source: Path, root: Path) -> int:
    if not source.exists():
        print(f"Clippings file not found: {source}", file=sys.stderr)
        print("Is the Kindle plugged in?", file=sys.stderr)
        return 1
    copies = root / "data" / "clippings"
    copies.mkdir(parents=True, exist_ok=True)
    stamp = datetime.now().strftime("%Y-%m-%d-%H%M%S")
    copy_path = copies / f"{stamp}-My Clippings.txt"
    shutil.copy2(source, copy_path)
    clips = dedupe(parse_clippings(copy_path.read_text(encoding="utf-8")))
    books = group_books(clips)
    synced_on = datetime.now().strftime("%Y-%m-%d")
    new_clips, changed = write_vault(books, root / "vault" / "books", synced_on)
    print(
        f"{new_clips} new clips across {changed} books "
        f"({len(clips)} clips in {len(books)} books total)"
    )
    return 0


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(
        description="Sync Kindle clippings into the Obsidian vault."
    )
    parser.add_argument(
        "source", nargs="?", type=Path, default=DEFAULT_SOURCE,
        help="path to My Clippings.txt (default: mounted Kindle)",
    )
    args = parser.parse_args(argv)
    return run(args.source, Path(__file__).resolve().parent)


if __name__ == "__main__":
    sys.exit(main())
```

### Task 10: CLAUDE.md — the wiki schema

**Files:**
- Create: `CLAUDE.md`

**Interfaces:**
- Consumes: the book file format from Task 6 (block IDs, `last_synced` frontmatter).
- Produces: the ingest and lint operations the agent (and Task 11/12) will follow.

- [ ] **Step 1: Write `CLAUDE.md` with exactly this content**

````markdown
# kindle-wiki

Kindle highlights → Obsidian LLM wiki. `sync.py` generates `vault/books/*.md`
from the Kindle's My Clippings.txt. You (the agent) maintain the wiki in
`vault/concepts/` using the operations below. Open `vault/` in Obsidian to
see the graph.

## Layout

- `vault/books/` — GENERATED sources. Never edit these; sync.py overwrites
  them wholesale.
- `vault/concepts/` — the wiki. You create and update these pages.
- `vault/concepts/_index.md` — concept list plus per-book ingest record.

## Book file format

Each clip block ends with a block ID (for example `^3f9c2a1b7d04`).
Highlights are blockquotes with a metadata line; notes are `Note:`
paragraphs; bookmarks are single metadata lines. Frontmatter carries
`title`, `author`, and `last_synced`.

## Concept pages

`vault/concepts/<Concept Name>.md`:

```markdown
---
summary: One sentence stating the concept.
---

# <Concept Name>

One short paragraph explaining the concept in your own words.

## Quotes

![[peak#^3f9c2a1b7d04]]

## Related

- [[Other Concept]] — one line on the relationship.
```

Rules:
- Embed quotes with `![[book-slug#^id]]`. Never copy quote text into a
  concept page — the book file is the single source of truth.
- Link books and other concepts with wikilinks; the Obsidian graph is built
  from these links.
- Concept names: short noun phrases, Title Case, singular ("Feedback Loop",
  not "feedback loops").

## _index.md format

```markdown
# Index

## Concepts

- [[Deliberate Practice]] — focused, feedback-driven practice at the edge
  of ability.

## Ingest record

- peak — last ingested 2026-07-09
```

## Operations

### Ingest ("ingest", "ingest new highlights")

1. Read `vault/concepts/_index.md` (create it from the format above if
   missing). For each file in `vault/books/`, compare its `last_synced`
   frontmatter to the ingest record; collect books that are new or newer.
2. For each collected book, read its highlights and notes. Skip bookmarks —
   they carry no text to cite.
3. Assign each clip to 1–3 concepts. STRONGLY prefer existing concept names
   from the index; create a new concept page only when nothing fits. Never
   create a near-synonym of an existing concept.
4. Update concept pages: add embeds under `## Quotes`, keep the summary
   paragraph current, maintain `## Related` links.
5. Update `_index.md` last: add new concepts to the list, set each ingested
   book's record to its `last_synced` date.
6. Report: books ingested, clips assigned, concepts touched, concepts
   created.

### Lint ("lint", "lint the wiki")

1. Near-duplicate concepts (synonyms, singular/plural, overlapping scope):
   report pairs with a proposed merge direction. Do NOT merge without the
   user's approval.
2. Broken embeds: `![[book#^id]]` targets that no longer exist in
   `vault/books/`. Report each.
3. Orphan pages: concept pages missing from `_index.md` or with zero quotes.
4. Index drift: `_index.md` entries whose page is missing, or pages absent
   from the index. Fix drift directly (it is mechanical); report everything
   else.

## Constraints

- Never edit `vault/books/` or `sync.py` during ingest/lint.
- No emojis anywhere.
- Keep concept pages short: summary, one paragraph, quotes, related links.
````
